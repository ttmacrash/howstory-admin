아직 연결 전이에요

config.js 에 Supabase 주소와 키를 넣으면 이 화면이 로그인 화면으로 바뀌어요.

  1. supabase.com 에서 무료 프로젝트 만들기
  2. SQL Editor 에 supabase/schema.sql 내용 붙여넣고 실행
  3. Authentication → Users → Add user 로 관리자 계정 만들기
  4. Project Settings → API Keys 의 URL 과 publishable key 를 config.js 에 입력
